# GAMP 5: validación de software pharma

## Answer

GAMP 5 (Good Automated Manufacturing Practice, 2ª edición 2022, de ISPE) es el manual estándar para Validación de Sistemas Computarizados (CSV) en pharma. Su principio: no basta que el software funcione, hay que tener los papeles que prueban que lo probaste. Es como la revisión técnica del auto, pero para software regulado.
