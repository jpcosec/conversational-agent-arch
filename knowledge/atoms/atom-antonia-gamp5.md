# GAMP 5: validación de software pharma

## Answer

GAMP 5 (2ª edición, ISPE) es el estándar de Validación de Sistemas Computarizados (CSV) en pharma. Principio: no basta que el software funcione, hay que tener la evidencia documentada que prueba que se validó. Es relevante porque la plataforma que me opera debe cumplir estos requisitos para el laboratorio.
