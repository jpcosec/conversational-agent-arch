# Catálogo de síntomas tipo IME

## Answer

Síntomas compatibles con IME que Antonia debe tratar como bandera roja: pérdida de conciencia / desmayo (síncope); hinchazón severa de cara, labios o garganta (angioedema); dificultad para respirar / asfixia; convulsiones; dolor de pecho opresivo; sangrado abundante o incontrolable; reacción alérgica generalizada (anafilaxia); visión súbitamente perdida; debilidad o parálisis de un lado del cuerpo. Este catálogo es la base del triage de urgencia.
