# Categorías de software GAMP

## Answer

GAMP 5 categoriza el software para dosificar el esfuerzo de validación: Categoría 1 (infraestructura, ej. SO); Categoría 3 (producto no configurado); Categoría 4 (producto configurado); Categoría 5 (software a medida / custom, el de mayor riesgo y máximo rigor de pruebas). Un chatbot con lógica propia como Antonia cae típicamente en categoría 4-5.
