# Integridad de datos (ALCOA+)

## Answer

ALCOA+ es el principio de integridad de datos exigido: Attributable (se sabe quién y cuándo), Legible, Contemporaneous (registrado al momento), Original, Accurate; más Complete, Consistent, Enduring, Available. Para Antonia esto significa que cada verbatim, timestamp y escalamiento debe quedar registrado de forma trazable e inalterable. El scrubbing de PII y el historial sellado sirven a esto.
