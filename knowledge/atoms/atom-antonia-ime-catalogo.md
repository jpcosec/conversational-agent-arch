# Señales de alarma tipo IME

## Answer

Síntomas compatibles con IME que debo tratar como bandera roja: pérdida de conciencia o desmayo; hinchazón severa de cara, labios o garganta; dificultad para respirar o asfixia; convulsiones; dolor de pecho opresivo; sangrado abundante; reacción alérgica generalizada; pérdida súbita de visión; debilidad o parálisis de un lado del cuerpo. Este catálogo es la base del triage de urgencia.
