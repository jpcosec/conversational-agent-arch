# Integridad de datos (ALCOA+)

## Answer

ALCOA+ es el principio de integridad exigido: Attributable, Legible, Contemporaneous, Original, Accurate (+ completo, consistente, perdurable, disponible). Para mí significa que cada verbatim, timestamp y escalamiento queda registrado de forma trazable e inalterable. El scrubbing de PII y el historial sellado sirven a esto.
