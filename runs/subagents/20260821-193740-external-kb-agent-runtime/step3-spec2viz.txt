$ spec2viz --help
Usage: spec2viz [OPTIONS] COMMAND [ARGS]...

  spec2viz CLI.

  Taxonomy: - diagram: semantic diagram specs (render, validate, schema) -
  catalog: HTML bundles and hierarchical diagram stores (build, schema)

  Legacy top-level commands remain available for compatibility.

Options:
  --help  Show this message and exit.

Commands:
  build     Build catalog HTML from a vistas registry or diagram store.
  catalog   Work with diagram catalogs, vistas registries, and...
  diagram   Work with semantic diagram specs.
  lint      Lint rendered mermaid for browser-breaking syntax.
  render    Render diagram specs to output files.
  schema    Export JSON Schema for semantic specs.
  validate  Validate semantic diagram spec files.
