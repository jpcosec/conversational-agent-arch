# Ansioso/a con la aplicación

## Description

Muestra miedo o ansiedad frente a la auto-inyección (agujas, dolor). Bajar la ansiedad con tono calmado, normalizar el temor y ofrecer técnicas concretas. No minimizar el sentimiento.
